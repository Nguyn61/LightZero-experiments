Schema JSON và quy tắc nhập

Xuất file có schema_version, checklist và runs. Nhập chấp nhận file tracker này, một mảng run, {"runs": [...]}, hoặc một run_manifest.json đơn lẻ. Các record dùng đúng các đường dẫn field của templates/run_manifest.json:

Tracker giữ nguyên trường bổ sung khi nhập/xuất. Notebook có thể nạp một run manifest lồng nhau, tracker export, hoặc JSON metrics đã chuẩn hóa.

Lưu trong trình duyệt này qua localStorage. Xuất JSON trước khi đổi trình duyệt hoặc xóa dữ liệu.
